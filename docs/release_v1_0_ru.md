# S.A.N.A. v1.0 Release Readiness

## Статус

v1.0 готова как инженерный шаг к локальной модели без обязательного внешнего API key.

## Область версии

- Усилен Ollama-compatible provider.
- Добавлены бюджеты генерации и длины ответа.
- Добавлена защита от случайного внешнего Ollama endpoint.
- Добавлены тесты на provider payload, output cap, malformed response и smoke gate для внешнего URL.
- Safety-first pipeline не ослаблен: crisis, emergency и minor safety остаются deterministic.

## Проверки

Перед релизом должны проходить:

```bash
make dev-cycle
make evaluate
make evaluate-readiness
```

`make llm-smoke` без ручных gate-флагов должен завершаться кодом `2`, потому что сетевой smoke запрещен по умолчанию.

## Известные ограничения

- На текущем сервере нет GPU для обучения большой модели с нуля.
- CPU-only inference может быть медленным на моделях больше 8B.
- Preflight модели пока не реализован: если Ollama запущена без нужной модели, ошибка будет поймана через fallback.
- Streaming пока отключен, чтобы не отдавать пользователю непроверенные частичные ответы.

## Решение

v1.0 можно считать готовой, если:

- все автоматические тесты проходят;
- evaluation остается зеленым;
- smoke без ручных разрешений блокируется;
- Git commit содержит код, тесты и документацию.
